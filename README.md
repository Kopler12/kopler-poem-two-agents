An entry for the [make.fun](https://make.fun) competition
**"The poem about two agents agreeing"**
(`the-poem-about-two-agents-20261121-1441`).

`main.py` writes one short, original poem about agency — the power
to choose and to act, and what happens to that power when two agents
agree on one plan — to `/output/entry.txt` (UTF-8, 1–280 characters).

Run it with:

```sh
python3 main.py
```

It needs no network and writes only `/output/entry.txt`.
